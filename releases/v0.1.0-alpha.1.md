# FRS v0.1.0 Alpha 1

**Pre-release for technical evaluation only — not approved for live attendance.**

FRS is an experimental Flutter Android kiosk and FastAPI backend for multi-frame face-based attendance. This alpha packages the Android debug build after automated Python and Flutter checks pass.

## Included

- Multi-frame camera capture in the Android kiosk.
- Client contracts for employee-scoped verification and roster-scoped identification.
- Separate device and administrator credentials.
- FastAPI backend, attendance policy, audit records, model registry and admin console.
- Python compile/lint/unit-test gate and Flutter analysis/test/Android debug-build gate.
- Setup, security and release documentation.

## Artifact

- app-debug.apk — Android **debug** build for development and integration testing. It is not a production-signed APK.

## Important limitations

- Compatible real model weights are not bundled. Operators must provide individually verified artifacts, provenance, checksums, licensing and preprocessing contracts.
- Recognition thresholds have not been calibrated or certified on deployment-specific data.
- Presentation-attack/liveness resistance has not been validated on a representative attack dataset.
- Actual target-device camera behavior and a complete deployment end-to-end test remain outstanding.
- No biometric accuracy, fairness, spoof-resistance, or production-readiness claim is made.

Do not use this alpha to make real employment, payroll, access-control or attendance decisions. See [RELEASE_CHECKLIST.md](../RELEASE_CHECKLIST.md) for required release gates.
